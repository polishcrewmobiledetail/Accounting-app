# Polish Crew — Accounting (Whitelabel PWA)
- Dark, futuristic UI
- Jobs-only flow (Quote → Book → Work → Pay)
- Gear-only "More…" drawer (Menu, Mileage, Transactions, Expenses, Export/Import, Settings)
- **Whitelabel**: edit header title and upload your own logo in Settings (stored locally)
- Offline (PWA) with JSON/CSV export

## Deploy (GitHub Pages)
1. Create/empty the repo.
2. Upload these files to the repo root:
   - `index.html`, `manifest.json`, `service-worker.js`, `icon-192.png`, `icon-512.png`, `logo-header.png`, `.nojekyll`
3. Settings → Pages → Deploy from a branch → Branch: `main` (root).
4. Open your site and do a **hard refresh**.
